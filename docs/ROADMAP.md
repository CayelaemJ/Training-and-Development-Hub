# Product Roadmap and Acceptance Criteria

## Phase 1 — Foundation (feature branch)

- [x] Self-owned profile and separate evidence types
- [x] Personal development profile page
- [x] Organization-published opportunities
- [x] Scoped pending permission requests, approval, denial and revocation
- [x] Employer read audit with seven-day expiry
- [x] Employer access disabled by default
- [x] Architecture/API/privacy/release documentation
- [ ] Schema migration reviewed against deployment database
- [ ] CI plus full browser E2E passes
- [ ] Security unit/integration tests and privacy sign-off

## Phase 2 — Eligibility and portable records

- [ ] Adult/guardian verification and child safeguarding
- [ ] Schools/university verified credential issuer controls
- [ ] Portable identity across institutions and pseudonymous identifiers
- [ ] Learner/guardian export, correction, deletion and portability workflows
- [ ] Data retention, account closure and breach handling
- [ ] Independent audit and vulnerability testing

## Phase 3 — Corporate subscription

- [ ] Employer verification and billing provider integration
- [ ] Paid entitlements enforced on the server, not just hidden in the UI
- [ ] Recruitment vacancy lifecycle, applications, messaging, abuse reporting
- [ ] Rate limiting, consent notice versioning, purpose-bound access and expiry
- [ ] Applicant-friendly, non-discriminatory accessibility and appeals

## Phase 4 — Explainable growth insights

- [ ] Evidence provenance and educator verification
- [ ] Optional validated self-reflection assessments with appropriate limitations
- [ ] Learning-gap and growth trends with longitudinal benchmarks
- [ ] Explainable suggestions with sources and uncertainty
- [ ] Human-reviewed career guidance and no automatic hire/reject decisions
- [ ] Fairness, validity, reliability and disparate-impact assessments

## Definition of done

A feature requires functioning UI, server-enforced authorisation, database migration, privacy review as applicable, tests, docs, a rollback plan and observed production health. Claims of official NSC/IEB compliance or psychometric validity require independent professional validation.
